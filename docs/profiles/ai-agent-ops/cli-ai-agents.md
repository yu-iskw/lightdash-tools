# CLI reference: AI agents

AI agent CLI commands live under `lightdash-tools agents` and `lightdash-tools ai-agents`.

Discovery:

- CLI: `lightdash-tools agents --help` / `lightdash-tools ai-agents --help`
- MCP: connect the `ai-agent-ops` profile and call `tools/list`

The former operation-catalog table generator (`scripts/generate-cli-docs.mjs`) was removed with the operations catalog.
