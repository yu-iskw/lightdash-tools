# Content-reader endpoint inventory

Capability map for the `content-reader` MCP profile (OpenAPI pin in `config/lightdash-openapi-ref.txt`). See [ADR-0012](../../adr/0012-mcp-content-reader-profile-saved-content-execution-boundary.md) for project scope/budgets and [ADR-0027](../../adr/0027-mcp-content-reader-opaque-saved-sql-chart-execution.md) for opaque saved SQL chart execution.

| Capability         | Method | Path                                                              | Client                                | Notes                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------ | ------ | ----------------------------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project get        | GET    | `/api/v1/projects/{projectUuid}`                                  | `v1.projects.getProject`              | Scoped to resolved project; omits `warehouseConnection` / `dbtConnection` ([ADR-0011](../../adr/0011-mcp-tool-response-sensitivity-classes.md))                                                                                                                                                                                                                                     |
| Content search     | GET    | `/api/v2/content`                                                 | `v2.content.searchContent`            | `projectUuids` forced to resolved project; sortBy: name, space_name, last_updated_at, views. Does not match chart UUIDs. Space `access` membership lists stripped ([ADR-0011](../../adr/0011-mcp-tool-response-sensitivity-classes.md))                                                                                                                                             |
| List verified      | GET    | `/api/v1/projects/{projectUuid}/content-verification`             | `v1.projects.listVerifiedContent`     | Admin-verified charts + dashboards; prefer as trusted seeds ([verified content](https://docs.lightdash.com/guides/verified-content))                                                                                                                                                                                                                                                |
| Spaces list        | GET    | `/api/v1/projects/{projectUuid}/spaces`                           | `v1.spaces.listSpacesInProject`       | Summary ACL                                                                                                                                                                                                                                                                                                                                                                         |
| Space get          | GET    | `/api/v1/projects/{projectUuid}/spaces/{spaceUuid}`               | `v1.spaces.getSpace`                  | Breadcrumbs + immediate content summaries; no membership lists                                                                                                                                                                                                                                                                                                                      |
| Dashboard get      | GET    | `/api/v2/projects/{projectUuid}/dashboards/{dashboardUuidOrSlug}` | `v2.dashboards.getDashboard`          | Metadata + tile layout; no query execution on GET                                                                                                                                                                                                                                                                                                                                   |
| Chart get          | GET    | `/api/v2/projects/{projectUuid}/saved/{chartUuidOrSlug}`          | `v2.saved.getSavedChart`              | Semantic charts only for full definition; SQL charts return opaque metadata (no SQL body). UUID lookups use the exact `uuids` filter. On **content-reader**, semantic GET 404 falls back to opaque SQL ([ADR-0027](../../adr/0027-mcp-content-reader-opaque-saved-sql-chart-execution.md)); the shared `get_chart` mount on content-developer maps that 404 to `CONTENT_NOT_FOUND`. |
| Parameters list    | GET    | `/api/v2/projects/{projectUuid}/parameters/list`                  | `v2.parameters.listProjectParameters` | Client method TBD                                                                                                                                                                                                                                                                                                                                                                   |
| Parameters get     | GET    | `/api/v2/projects/{projectUuid}/parameters`                       | `v2.parameters.getProjectParameters`  | Client method TBD; read by name only                                                                                                                                                                                                                                                                                                                                                |
| Run saved chart    | POST   | `/api/v2/projects/{projectUuid}/query/chart`                      | `v2.query.runChartQuery`              | Semantic saved charts; values-only parameter overrides                                                                                                                                                                                                                                                                                                                              |
| Run SQL chart      | POST   | `/api/v2/projects/{projectUuid}/query/sql-chart`                  | `v2.query.runSqlChartQuery`           | Opaque saved SQL chart results only; SQL text never returned ([ADR-0027](../../adr/0027-mcp-content-reader-opaque-saved-sql-chart-execution.md))                                                                                                                                                                                                                                    |
| Run dashboard tile | POST   | `/api/v2/projects/{projectUuid}/query/dashboard-chart`            | `v2.query.runDashboardChartQuery`     | Dashboard context + inherited filters; semantic tiles                                                                                                                                                                                                                                                                                                                               |
| Run dashboard SQL  | POST   | `/api/v2/projects/{projectUuid}/query/dashboard-sql-chart`        | `v2.query.runDashboardSqlChartQuery`  | Dashboard SQL tiles; opaque results ([ADR-0027](../../adr/0027-mcp-content-reader-opaque-saved-sql-chart-execution.md))                                                                                                                                                                                                                                                             |
| Query results      | GET    | `/api/v2/projects/{projectUuid}/query/{queryUuid}`                | `v2.query.getAsyncQueryResults`       | Bounded paginated rows (`resultCapability: bounded_aggregate_rows`)                                                                                                                                                                                                                                                                                                                 |
| Cancel query       | POST   | `/api/v2/projects/{projectUuid}/query/{queryUuid}/cancel`         | `v2.query.cancelAsyncQuery`           | In-memory ledger v1 correlates handles                                                                                                                                                                                                                                                                                                                                              |

**Excluded:** `POST …/query/metric-query`, `POST …/query/sql` (SQL Runner), `POST …/query/underlying-data`, `POST …/query/{queryUuid}/download`, `POST …/query/{queryUuid}/schedule-download`, `POST /api/v1/saved/{chartUuid}/export` (chart PNG — not mounted; use `run_chart`), dashboard `POST /api/v2/dashboards/{dashboardUuid}/exports`, and all content/org/project mutations (create, update, delete, move, bulk-action).
