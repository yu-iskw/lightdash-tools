# Content-reader endpoint inventory

Capability map for the `content-reader` MCP profile (OpenAPI pin in `config/lightdash-openapi-ref.txt`). See [ADR-0012](../../adr/0012-mcp-content-reader-profile-saved-content-execution-boundary.md), [ADR-0028](../../adr/0028-mcp-content-reader-executes-saved-dashboard-sql-tiles.md), and [ADR-0032](../../adr/0032-mcp-tool-result-artifacts-and-content-reader-sql-body-reveal.md) for execution and artifact boundaries.

| Capability             | Method | Path                                                              | Client                                | Notes                                                                                                                                                                                           |
| ---------------------- | ------ | ----------------------------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project get            | GET    | `/api/v1/projects/{projectUuid}`                                  | `v1.projects.getProject`              | Scoped to resolved project; omits `warehouseConnection` / `dbtConnection` ([ADR-0011](../../adr/0011-mcp-tool-response-sensitivity-classes.md))                                                 |
| Content search         | GET    | `/api/v2/content`                                                 | `v2.content.searchContent`            | `projectUuids` forced to resolved project; sortBy: name, space_name, last_updated_at, views                                                                                                     |
| List verified          | GET    | `/api/v1/projects/{projectUuid}/content-verification`             | `v1.projects.listVerifiedContent`     | Admin-verified charts + dashboards; prefer as trusted seeds ([verified content](https://docs.lightdash.com/guides/verified-content))                                                            |
| Spaces list            | GET    | `/api/v1/projects/{projectUuid}/spaces`                           | `v1.spaces.listSpacesInProject`       | Summary ACL                                                                                                                                                                                     |
| Space get              | GET    | `/api/v1/projects/{projectUuid}/spaces/{spaceUuid}`               | `v1.spaces.getSpace`                  | Full ACL + inheritance                                                                                                                                                                          |
| Dashboard get          | GET    | `/api/v2/projects/{projectUuid}/dashboards/{dashboardUuidOrSlug}` | `v2.dashboards.getDashboard`          | Metadata + tile layout; no query execution on GET                                                                                                                                               |
| Chart get (semantic)   | GET    | `/api/v2/projects/{projectUuid}/saved/{chartUuidOrSlug}`          | `v2.charts.getSavedChart`             | Semantic charts; chart type drives execute eligibility                                                                                                                                          |
| SQL chart get (reveal) | GET    | `/api/v1/projects/{projectUuid}/sqlRunner/saved/{uuid}`           | `v1.sqlRunner.getSavedSqlChart`       | Authored SQL body; MCP attaches as artifact only when `includeArtifacts` contains `sql` ([ADR-0032](../../adr/0032-mcp-tool-result-artifacts-and-content-reader-sql-body-reveal.md))            |
| SQL chart by slug      | GET    | `/api/v1/projects/{projectUuid}/sqlRunner/saved/slug/{slug}`      | `v1.sqlRunner.getSavedSqlChartBySlug` | Same reveal path by slug                                                                                                                                                                        |
| Parameters list        | GET    | `/api/v2/projects/{projectUuid}/parameters/list`                  | `v2.parameters.listProjectParameters` |                                                                                                                                                                                                 |
| Parameters get         | GET    | `/api/v2/projects/{projectUuid}/parameters`                       | `v2.parameters.getProjectParameters`  | Read by name only                                                                                                                                                                               |
| Run saved chart        | POST   | `/api/v2/projects/{projectUuid}/query/chart`                      | `v2.query.runChartQuery`              | Semantic saved charts only; values-only parameter/filter overrides; rows as data artifact by default                                                                                            |
| Export chart image     | POST   | `/api/v1/saved/{chartUuid}/export`                                | `v1.charts.exportChartImagePng`       | Single PNG snapshot (`resultCapability: image_snapshot`); requires headless browser; not CSV/bulk download                                                                                      |
| Run dashboard tile     | POST   | `/api/v2/projects/{projectUuid}/query/dashboard-chart`            | `v2.query.runDashboardChartQuery`     | Dashboard context + inherited filters; semantic `saved_chart` tiles                                                                                                                             |
| Run dashboard SQL tile | POST   | `/api/v2/projects/{projectUuid}/query/dashboard-sql-chart`        | `v2.query.runDashboardSqlChartQuery`  | Saved `sql_chart` tiles only (`savedSqlUuid`); values-only filter/parameter overrides; `dateZoom` ignored ([ADR-0028](../../adr/0028-mcp-content-reader-executes-saved-dashboard-sql-tiles.md)) |
| Query results          | GET    | `/api/v2/projects/{projectUuid}/query/{queryUuid}`                | `v2.query.getAsyncQueryResults`       | Bounded paginated rows as data artifact by default (`resultCapability: bounded_aggregate_rows`)                                                                                                 |
| Cancel query           | POST   | `/api/v2/projects/{projectUuid}/query/{queryUuid}/cancel`         | `v2.query.cancelAsyncQuery`           | In-memory ledger v1 correlates handles                                                                                                                                                          |

**Standalone SQL chart execute (API exists; MCP disabled):**

| Capability    | Method | Path                                             | Client | Notes                                          |
| ------------- | ------ | ------------------------------------------------ | ------ | ---------------------------------------------- |
| Run SQL chart | POST   | `/api/v2/projects/{projectUuid}/query/sql-chart` | —      | Not on MCP allowlist; `CONTENT_NOT_EXECUTABLE` |

**Excluded:** `POST …/query/metric-query`, `POST …/query/sql`, `POST …/query/underlying-data`, `POST …/query/{queryUuid}/download`, `POST …/query/{queryUuid}/schedule-download`, dashboard `POST /api/v2/dashboards/{dashboardUuid}/exports`, and all content/org/project mutations (create, update, delete, move, bulk-action). Single-chart PNG via `export_chart_image` is allowed (ADR-0012 carve-out).
